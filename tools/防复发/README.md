## 双向验证的 needs

`none`：只要 python3 + PyYAML；`pip`：再加 numpy scipy pyloudnorm soundfile jieba num2words lameenc ——这两类每次推送都在 GitHub 上跑。`tts` / `browser` / `heavy` 只在本机（`--测试`、`--测试 --全部`）。
测共用代码时用 `验证/_抽取.py` 只抽出要测的函数（不 import 整个模块，免得拉进语音模型），测的就是仓库里正在用的那份。

## 新铁律的规矩

CLAUDE.md 新加一条铁律，同一次提交要在 `规矩登记.json` 登记（由哪段程序保证、双向验证命令）；能做成钩子或检查的一律做成，做不成的写明缺口。

## 新坑的提交规矩

一条新坑必须**同一次提交**带齐：① 检查程序（自动跑在流水线里）② 双向验证命令（埋雷能报出、修好为 0）③ `踩坑登记.json` 条目 ④ CLAUDE.md 踩坑表一行。
缺任何一样，提交前钩子拦下。补检查时同一类坑**所有项目一起查**（规则只写一处，如 `tools/text_rules.py`）。

## 启用

新开会话时 `.claude/settings.json` 的 SessionStart 钩子自动执行 `git config core.hooksPath .githooks`。手动：`git config core.hooksPath .githooks`。
