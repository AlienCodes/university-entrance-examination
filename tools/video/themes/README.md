# 共用背景样式库（6 种，各项目共用）

2026-10-16 起由西班牙语、专八共用（以后新项目直接用）。中考设计库（`中考/tools/样式设计/`）的 6 种背景原样搬到这里，一份基础样式、一份字体、一套检查，
各项目只写自己的“调整”（封面结构、页眉文字等），追加在基础样式之后覆盖。

| 文件 | 内容 |
|---|---|
| `themes.json` | 索引：编号 1–6、名称、基础样式文件、用到的字体、特点 |
| `css/1_晴空校园.css` … `6_柔彩插画.css` | 基础样式（1–4、6 = `中考/tools/样式设计/样本/Z*.css`，5 = 中考正式生产版 `中考/tools/样式.css`，逐字节相同） |
| `fonts/` | 1–6 用到的网页字体（Nunito、Fredoka、Baloo 2、思源黑体、站酷快乐体、霞鹜文楷；SIL OFL 1.1，许可证在各目录 LICENSE） |
| `themes.py` | `css(编号, 项目调整文件)`、`FONTS_CSS`、`files(编号)`（指纹用）；截图前的程序检查 `GLYPH`（每个字都由样式字体画出）、`HBOX`（横向不出界）、`COVER`（封面各块不出界、不重叠） |

各项目的调整：

| 项目 | 调整文件 | 样式 C（项目自己的默认画面） |
|---|---|---|
| 西班牙语 | `西班牙语/tools/样式/<同名>.css`（西语封面：西语标题 + 中文标题 + 插图） | 四级设计方案 C「经典杂志」 |
| 专八 | `专八/tools/样式/<同名>.css`（专八封面、页眉） | 「书卷水墨」`专八/tools/样式.css` |

搬家时的核对（2026-10-16）：西班牙语 es01 的 7 种样式共 70 屏，新旧程序生成的 HTML 除字体文件路径外逐字节相同；截图逐像素比较，只有 3 屏各 1—4 个像素差 6—9 级，
与旧程序自己重复截图的差别相同（浏览器光栅化的随机抖动）；按西班牙语工具包的打包清单组装一遍，在工具包里截图同样一致。
