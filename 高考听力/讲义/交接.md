# 高考听力分套电子资料与小店商品图

## 当前交付（2026-11-13）

用户要求每套单独成夹，新增汉译英听写卡与逐题详解，所有内容对应同一份听力题；文件舒适易读。原来的八份全局合订PDF保留为制作来源，现行买家ZIP改为50个匹配文件夹。

每套九份PDF：听力练习册、原文双语精读、词汇与短语讲解、汉译英听写卡及答案、原文听写训练本及答案、听力逐题详解、本套复习记录表。每套另附匹配的原始Word与使用说明。共450份PDF、5491页、1000题、7731行按套汉译英卡。

汉译英卡为单列竖排，左中文、右空白，词性也转为中文；同类同义提示合并并在答案中并列本套表达。原文听写训练保持关键词挖空形式，两种训练分开。词汇讲解包含语境义、真实例句及译文、原文词形和精读句号。详解每题包含答案、题干与选项中文、原文依据及中文、推理和其他选项说明，不再单独宣传“真题参考答案”。

## 制作、核验与商品图

- tools/分套资料.py以当前详解生成练习、词汇、卡、答案、详解与复习表，按原合订PDF精确章节抽取精读和两种原文听写资料，改为本套页码。全套输出分套资料/；核验/分套/和分套资料清单与核验.json核每套9份、SHA、页数、Word与当前详解SHA。
- 新增PDF通过实际字体载入、自动换行/宽度检查、正文完整提取、答案不泄入卡片检查；字体和A4检查通过。详解结构与引用关卡覆盖1000题，图片直接取最终PDF原样渲染。
- 商品图13张：主图、实际50目录、单套文件清单、九类真实内页、交付说明。主图保留淡紫奶油底、紫色大字、橙色更新标签与热气球；新增汉译英卡及逐题详解。左下角无排序序号，使用“打开后”。外框由浏览器渲染，PDF内页与局部从实际交付文件取图，不生成假页面。
- 商品图/真实展示.py核对实际买家ZIP及样例套PDF哈希，图文核对.json记录源页码、文件哈希与图片哈希。目录包含溢出检查。当前截图目录仅留本版18份真实样图，预览PDF18页。

## 重建命令与发布

在有Playwright/PyMuPDF/pypdf及项目字体的环境中：

```
python 高考听力/讲义/tools/详解数据.py duplicate
python 高考听力/讲义/tools/详解数据.py check
python 高考听力/讲义/tools/分套资料.py --build
python 高考听力/讲义/tools/分套资料.py --verify
python 高考听力/讲义/tools/打包.py --materials-only
python 高考听力/讲义/商品图/真实展示.py --build
```

详解少量更新可用分套资料.py --refresh-details --cases 套号，仅重做该套练习与详解；如词汇/版式改变，则重做受影响套的全部PDF。检查实际商品图后写图文核对.json并运行打包.py。图片或根说明更新使买家ZIP SHA变化时，需要重新生成图文核对来源。

工作流release-gaokao-listening-materials.yml用GitHub Actions打包、替换两个Release资产并回下载，核SHA、CRC与中文UTF-8。当前控制为all，因为实际学习资料与商品图一起扩充；不再用只更新图片的shop模式。Release仍为 https://github.com/AlienCodes/university-entrance-examination/releases/tag/gaokao-listening-materials 。本次发布完成证据单独写核验/分套资料发布核验.json。
