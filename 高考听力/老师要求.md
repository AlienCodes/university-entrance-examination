1. **（2026-11-10）题目字号尽可能大**：显示题目时字体越大越好，充分利用整个屏幕，让高考学生练题时看得清清楚楚。
   - 做法：版式按实测挑最大字号（参照六级听力 `layout` 从大往小试、排版检查 0 处），不写死字号；题干和选项都放大；
   - 检查：截图阶段量题干 / 选项字高（按 1920×1080 量），设下限，低于下限报错不出图；样片先给老师看字号再批量。
2. **（2026-11-10）材料上传**：大文件（500 MB 以上）走 GitHub Release，tag `gaokao-listening-raw`。
3. **（2026-11-10）按高考的小节 / 材料分组显示题目，不是一题一屏**：老师原话“高考他是按小节来做的”。一段录音对应几道题，屏上就同时放这几道题（如第一节短对话、第二节每段长对话 / 独白对应的 2—4 题；考试说明里“听第 X 段材料，回答第 a 至 b 题”就放 a—b 题），学生读题、作答期间这一组题都在屏上；在“这一组题必须同屏”的前提下，字号挑放得下的最大。分组以试卷原文的说明为准，程序核对：每屏题号 = 该段材料说明里的题号范围，缺一题、多一题都报错。
4. **（2026-11-10）材料已上传**：Release `gaokao-listening-raw` 的 `default.zip`（531 MB，sha256 9270b3f9…00a2），解压到单独的空目录再看。
5. **（2026-11-10）整体样式跟四六级听力视频版一样：白纸黑字的试卷风格**，倒计时、读题时间、作答停顿、片头片尾等每一处都要认认真真做到完美（老师原话“非常非常非常完美”）。
6. **（2026-11-10）开头不要冗长的前置音**：原音最前面的音乐、试音、通用考试说明、长篇开场白一律剪掉，打开视频尽快进入正题——从“第一节”说明（或第一段对话前的读题提示）开始。
   - 这是铁律 25（原音不动）的一处明确例外，范围只限**剪掉开头**：保留部分与原音逐样本相同（不增益、不压缩、不重采样），只许再插答题停顿；
   - 程序保证：剪切点由语音识别找“第一节 / Section A”这类锚点定位（锚点必须恰好一处），剪后与原音对应段逐样本比对；开头 1.5 秒静音片头照旧；
   - 写进 `tools/防复发/验证/原音不动.py` 的例外登记（只许剪开头、剪的一段只许是锚点之前），并双向验证（剪到锚点之后、剪中间段都必须报）。
7. **（2026-11-10，老师强调“特别重要”）片头写明年份和试卷**：视频开头的片头屏醒目写出“××××年 ××卷 高考英语听力”（如 2025年 全国一卷 / 新课标Ⅰ卷、上海卷（春考）等，同一年两次考试写明场次，照铁律 6），文件名同样写明。
   - 程序保证：片头文字 = 该套数据里的年份 + 卷名（从试卷原文 / 文件名核对，不能空、不能是“未知”），文件名正则同一份（踩坑 108）；年份和卷名任何一项对不上、缺了就报错不出图。
