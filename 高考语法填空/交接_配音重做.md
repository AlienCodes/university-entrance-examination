## 按顺序做

### 1. 去呼吸声（新音质处理，程序保证）

**已知线索：**
- `讲解音频.inner_parts` 用“比本段最响处低 42 dB 以内”算有声，吸气声在门限以内，被算进意群；
- `per_clause` 给每个意群做 even、level_clause，吸气声跟着被抬高；
- `G.trim` 的门限是 −48 dB，段首的吸气也留着；
- 意群之间已经是真静音（per_clause 填零），所以呼吸主要在意群内部和意群边缘。

**做法：**
1. 先量：对比原始合成与样音 A，用程序量出停顿和呼吸段的电平。吸气是宽带噪声：无周期性、高频占比高、持续 0.2—0.6 秒，位置在词与词之间。
2. 在任何电平处理之前，按识别器的词时间戳，或者按周期性加频谱特征，找出词间的非语音段，换成真静音，两头加短淡入淡出。
3. 词首、词尾的清辅音（s、f、h、th）留足余量，不许切（踩坑 27）。
4. 改完跑识别比对，证明没吞字、没吞词尾。

**新检查：** 成品里每个停顿（以及呼吸段）的最大电平低于门限，门限按实测定。

**登记踩坑 89，带双向验证：** 旧样音 A 必须报出，修好后为 0。验证不许依赖 git 历史（CI 浅检出）。

### 2. 语气更自然

1. **指令写法：** 试几种往“真人老师当面讲题”调的写法（热情、口语化、有起伏、重点词加重、语速有快有慢）。
   - CustomVoice 有 instruct；Base 的 clone 模式没有 instruct，语气靠参考音频。
   - 可以重新设计一段更口语、更有讲课感的参考音频。
2. **更长的段落合成：** 上下文更长，语调更连贯。段落过长时识别比对和选段照做。
3. **稿子再口语化：** 加“好，我们来看”“注意啊”“对吧？”这类口头衔接，长短句交错，停顿跟着意思走。
   - 改完跑 `稿检查.py`（含 `--自检`）。
   - 改动大就再派一位复核员加埋雷。
4. **再试 1—2 个别的开源、可商用模型做同稿对比：** 比如 CosyVoice 3、IndexTTS-2。
   - 先核实许可证；不克隆真人：参考音频只用 VoiceDesign 生成的设计音色。
   - 不用 Google / gcloud，不用 edge-tts。
5. 响度规矩不放宽（铁律 2）。
