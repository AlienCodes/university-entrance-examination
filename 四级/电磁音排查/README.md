# 电磁音排查记录（2026-10-08）

1. 用户反映视频有电磁音。频谱分析发现原始合成里有声码器的固定频率窄带音（4800/9600 Hz 等，9600 Hz 高出周围约 11 dB）。
2. 用 65 个极窄陷波去掉这些窄带音 → 用户对比试听：**处理后电磁音明显更大**（高 Q 陷波在辅音、字头处余振出细音）。已撤销，相关音频恢复。
3. 单一因素试听（`试听_先A后B.mp3`）：
   - A：已发布第一批视频里的原声（完整处理链）→ 用户：**没有电磁音**
   - B：同一男声的原始合成，不做后期处理 → 用户：**有电磁音**
4. 结论：电磁音存在于原始合成；完整处理链后的成品没有。视频不需要重做。
   之前发给用户的“逗号停顿对比”样音是原始合成，用户很可能是从那里听到的。
5. 规定（写入 CLAUDE.md 铁律第 10 条）：任何给用户的音频，包括样音，都必须走完整处理链；任何新的音质处理先做对比样音给用户试听确认。

其余 `0_`–`8_` 单段试听保留备查（`1_` 走完整处理链，`2_`–`8_` 为原始合成）。

## 第二轮（用户：第一批成品认真听仍有很轻的电磁音）

6. 试了专门的语音降噪神经网络 DeepFilterNet3（`四级/tools/denoise.py`）：整体只变 0.2 dB，电磁音频点完全没变（9600 Hz +11.4 → +11.3 dB）。
   原因：音频里没有“背景噪声”——停顿处本来就是绝对无声，电磁音是叠在人声上的，降噪模型把它当成人声的一部分。不采用。
7. 逐帧压频点（STFT）：9600 Hz 只降到 +9 dB，4 kHz 以上整体变暗 2–4 dB，改变了音色。不采用。
8. 候选方案 `四级/tools/debuzz.py`：只处理 46 篇里每篇都有、高出周围 5 dB 以上的 9 个固定频点；带宽 60 Hz（余振约 5 毫秒）；单向滤波（字头前不出现任何东西）。
   c40 实测：9 个频点全部压到周围以下约 20 dB；4 kHz 以下人声 0.00 dB 变化，4–8 kHz −0.4 dB，8–12 kHz −1.2 dB；字头前无任何改动。
   **待用户看 c40 样片试听确认后才能用于成品。**
