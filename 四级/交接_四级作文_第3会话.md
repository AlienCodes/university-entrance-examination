## 四级与六级的不同（一定要改对）
- 字数：四级题目要求 120—180 词（以本题 prompt 为准），范文 168—180 词；本篇字数用程序算：`python3 -c "import sys,json;sys.path.insert(0,'tools');import 作文规则 as r;e=[x for p in __import__('glob').glob('四级/作文/20??.json') for x in json.load(open(p)) if x['id']=='<src>'][0];print(r.counted(e))"`（<src> 换成 sents.json 里的 src）。
- 四级没有“给定首句”。题型：情景作文、议论文、应用文（建议书 / 报告）、命题作文（标题 + 参考陈述）。有标题的篇目，标题不计入字数，审题里提醒“标题写在正文上方”。

- 所有引用（要求对照、得分、升格最后一步、句式范文原句、词汇）都必须是范文原样文字（程序逐字核对）。
