## 文件

- `已决定不改.json`：人工判断后保留原文的条目及理由（两轮意见相反的都在这里做了最终决定）。以后再精校时要把它放进审阅文件，避免同一处来回改。
- `埋雷位置.json`、`第二轮埋雷位置.json`：埋雷测试的故意错误。
- `第一轮查错_未完成.json`：第一轮中途暂停时保存的查错原始结果（旧编号，仅存档）。

## 判断标准（与高考部分一致）

认真的英语老师或专业编辑会判错的就改，“试卷原文就是这样写的”不是保留错误的理由；英式/美式拼写、合法的新闻文体、引语中的口语、可加可不加的逗号都不改。事实错误要查证后才改（如 c49 辛伐他汀“50 多年前”→“30 多年前”）。
