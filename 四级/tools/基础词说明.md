# 基础词（不要求标注的词）

`基础词.txt` 共 2316 个：初中词表（开源词库 KyleBing/english-vocabulary，经 npm 包 @ssbun/ev-cli 0.1.0）
与英语最常用的 1000 个词（Python 包 wordfreq 的 top_n_list('en', 1000)）的并集，含其规则变形和缩约形式。

用途：`ann_lib.py` 的覆盖检查。句子里**不在这份表里的词都必须标注**（用户要求：participant、interact 这类词一个都不能漏）；
专有名词、数字、全大写缩写除外。表里的词也可以标注（如用在不常见的意思或固定短语里）。

2026-10-09（六级）补充：基础助动词的否定缩写 hadn’t、hasn’t、shouldn’t、weren’t、mustn’t、needn’t（直撇号、弯撇号两种写法），与表中已有的 can’t、don’t、wasn’t 等同类；此前漏收，导致六级标注时被迫把 shouldn’t 之类当“短语”标注（复核人指出这是语法而非词汇）。四级 60 篇复查仍全部通过。
