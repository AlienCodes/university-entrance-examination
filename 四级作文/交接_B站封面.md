# 交接：四级写作视频 B 站封面（16:9 + 4:3）（2026-10-29）

用户要求：“绝对完美”，绝对能吸引考四级的人点进来；封面上一定要有「四级真题范文」「彻底搞定四级写作」。

## 结果

- 定稿 A（四级杂志纸面，与视频同一画风）：`四级作文/封面/系列封面/四级写作真题范文32篇_封面_16比9.{png,jpg}`（3840×2160）、`_4比3.{png,jpg}`（2880×2160）。
- 备选（16:9 JPG）：`…封面备选B_16比9.jpg`（深绿底居中大字，无截图）、`…封面备选C_16比9.jpg`（黄黑撞色，与四级阅读系列封面同色）。
- B 站标题、标签、简介：`四级作文/封面/B站标题与简介.md`（`标题与简介.py` 生成，标题 59/80 字、简介 1331/2000 字）。

## 为什么选 A

320×180 缩略图里 A 的主标题「彻底搞定 / 四级写作」两行、字最大（缩略图字高约 37 像素），「四级真题范文」墨绿实底白字第二大；
钩子「2026.6 已更新」红圆章；真实视频画面（c01 第 7 屏）告诉人点进去是什么样子，和视频本身的杂志画风一致。
B 最醒目但看不出视频长什么样；C 的「32篇四级真题范文」和「彻底搞定四级写作」两条一样大，抢焦点。

## 程序检查（`python3 四级作文/封面/系列封面.py 草稿 | 定稿 A | --自检`）

文字不出画、不进 B 站底角遮挡区、互不重叠、不压截图；圆章里的字在圆内（不旋转坐标量）；字体全部加载；
每个字都在所用字体的 cmap 里（fontTools，不许回退系统字体）；缩到高 180 后字号 ≥ 下限（主标题 24、钩子 13、卖点 10）；
画面上没有“数字/数字”；画面上的数字都是现算的（32 篇、11 次、2021—2026、2026.6）；两句必有的话都在。
`--自检`：正常 0 处；字号×0.5、放回“02 / 09”、篇数写成 31、塞进字体没有的字、圆章字放大到草稿的 0.3，A/B/C × 两种比例全部报出。

## 注意

- 字体 ttf（思源黑体 900/700、思源宋体 900）不进仓库（`四级/封面/fonts/.gitignore`），缺了脚本自动从 fonts.gstatic.com 下载。
- Python 要有 playwright、fonttools、Pillow（本容器 `pip install playwright fonttools`；浏览器用 /opt/pw-browsers/chromium）。
