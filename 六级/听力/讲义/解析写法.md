# 六级听力讲义 · 解析写法（给写解析的子代理）

材料：`scratchpad/mat/<套>.txt`（每组原文逐句带句号 [sid]，题目、选项、已核答案）。只读这一个文件。
产出：`六级/听力/讲义/解析/<套>.json`，然后跑 `python3 六级/听力/讲义/tools/解析检查.py <套>`，报几处改几处，直到 0。

```json
{"套": "201812-1", "题": {
  "1": {
    "答案": "A",
    "依据": [{"sid": 15, "句": "原文第 15 句里的逐字片段（≥3 词，就是听到答案的那几句话）"}],
    "讲": "先说依据、再说结论：女士说这本书……（转述依据），也就是说……，所以答案选 A。",
    "替换": [{"选项": "正确选项里的逐字片段", "原文": "依据句里的逐字片段", "类型": "同义改写"}],
    "错项": {"B": {"类": "没提到", "说": "一句话说清为什么错"}, "C": {...}, "D": {...}},
    "选项译": {"A": "…", "B": "…", "C": "…", "D": "…"}
  }, "...": {}}}
```

规则（程序会查）：
- 答案 = 材料里给的答案（已复核，不许改）；“讲”里写明“答案选 X”，只出现正确字母这一种“答案选”。
- 依据：1—3 条，sid 必须是本组原文的句号，“句”是该句的**逐字**子串（大小写、标点、弯撇号 ’ 都照抄），挑最能定位答案的那一段，不要整段照搬。
- 替换：1—4 条，“选项”是正确选项的逐字片段，“原文”是依据句的逐字片段，两边意思对应；类型只能是：同义改写 / 词性句式转换 / 正反转换 / 概括归纳 / 原词复现（两边完全相同才用“原词复现”）。尽量找出真正的“换说法”，这是学生最想学的。
- 错项：另外三个字母各一条，类只能是：没提到 / 张冠李戴（原文有，但说的是别人、别的事）/ 偷换（关键词或对象被换掉）/ 说反了 / 过度推断（原文意思被说过头）。“说”8—70 字，点到原文哪里或缺了什么。
- 选项译：四个选项都译成通顺的中文。
- 材料里题目后面标了“（缺念题句）”的题，另加 "题译": "题干的中文"。
- 讲：30—220 字，**先依据后结论**，有“因为 / 所以 / 也就是说 / 可见 / 对应”这类说法；按基础较弱的学生也能跟上来写：先说在哪儿听到（谁说的、哪句），再说这句话什么意思，再说和哪个选项对应。
- 中文要地道、口语自然（不要“进行了分析”“被……所……”、不堆“的”）；中文里用全角标点；不要直引号。
- 自己写，不抄任何出版社 / 网站的解析。
