## 每套试卷多少分

29 套都是完整的四部分试卷（写作、听力、阅读、翻译），**每套满分 710 分**，考试时间 130 分钟。试卷 PDF 不含答案，也不印分值；下面是六级的标准计分（全国大学英语四、六级考试委员会公布的分值比例）：

| 部分 | 题型 | 题量 | 每题分值 | 小计 | 占比 | 时间 |
|---|---|---|---|---|---|---|
| Part I 写作 | 短文写作 | 1 篇（150—200 词） | — | **106.5** | 15% | 30 分钟 |
| Part II 听力 | Section A 长对话 | 8 题 | 7.1 | 56.8 | 8% | 30 分钟 |
| | Section B 听力篇章 | 7 题 | 7.1 | 49.7 | 7% | |
| | Section C 讲座/讲话 | 10 题 | 14.2 | 142 | 20% | |
| | **听力合计** | 25 题 | | **248.5** | 35% | |
| Part III 阅读 | Section A 词汇理解（选词填空） | 10 空 | 3.55 | 35.5 | 5% | 40 分钟 |
| | Section B 长篇阅读（段落匹配） | 10 题 | 7.1 | 71 | 10% | |
| | Section C 仔细阅读（Passage One + Two） | 10 题 | 14.2 | 142 | 20% | |
| | **阅读合计** | 30 题 | | **248.5** | 35% | |
| Part IV 翻译 | 汉译英段落 | 1 篇 | — | **106.5** | 15% | 30 分钟 |
| **总分** | | 55 道客观题 + 2 篇主观题 | | **710** | 100% | 130 分钟 |

- 客观题（听力 + 阅读）共 497 分，主观题（写作 + 翻译）共 213 分。
- **Section C 仔细阅读两篇共 10 题、142 分**，是整张试卷里每题分值最高的题型之一（14.2 分/题）。
- 第 3 套试卷没有印听力（全国每次只考两套听力，第 3 套与前两套共用），但考试本身仍然考听力，满分同样是 710。
