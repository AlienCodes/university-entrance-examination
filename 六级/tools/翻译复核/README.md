缩写词条：第 2 轮复核人指出 shouldn’t、hadn’t、hasn’t 是语法而非词汇，不该当“短语”标注。原因是共用的基础词表漏收了这几个基础助动词的否定缩写（已有 can’t、don’t、wasn’t 等），已补进 `四级/tools/基础词.txt`（四级 60 篇复查仍全部通过），六级里这类词条全部去掉。

高亮写法补充：同一句里一个词出现多次、要标的不是第一处时，原文写法用 [ ] 标出真正高亮的词，其余只用来定位（`../ann_lib.py` 的 find），如 s23 第 14 句 `ideal{the [ideal] filter}`（前面两处 ideal 属于 beauty ideal）。
