# 六级长难句分析：写作要求（每批代理照此执行；用户 2026-10-21）

目的：帮学生**读懂**又长又复杂的句子——先抓主干、再把修饰成分一层层挂上去；**知道怎么翻译**；**知道句子里有哪些知识点**。读者是备考六级的大学生，讲解要准确、具体、好懂，不说空话。

## 你要做的
对指定篇目，读 `六级/长难句/挑句.json` 里该篇挑出的句子（k = 句子序号，从 1 数），句子原文和已定稿的参考译文在 `六级/data/vocab.json`（该篇 paras 里所有句子按顺序排列，第 k 句）。
为每一句写分析，存成 `六级/长难句/<篇目>.json`：
```json
{"pid": "s01", "sentences": [
  {"k": 2,
   "公式": "主句 + which 引导的非限制性定语从句 + 不定式短语作目的状语（一句话说清句子骨架）",
   "主干": {"主语": "原句片段", "谓语": "原句片段", "宾语/表语": "原句片段（没有就省略这一项）"},
   "拆解": [{"片段": "原句片段", "成分": "词表里的名称", "作用": "修饰谁 / 在句中做什么（如：修饰先行词 policies）", "说明": "为什么这样判断、读的时候注意什么"}],
   "读懂步骤": ["第一步：……", "第二步：……", "第三步：……"],
   "翻译": {"方法": ["词表里的方法"], "说明": "结合参考译文说明怎么处理语序、从句、长定语等"},
   "知识点": [{"名称": "词表里的名称", "例": "原句片段", "说明": "这个知识点是什么、在本句里怎么体现、怎么用"}]
  }]}
```
## 硬性规则（程序会逐条检查，不通过就退回）
- 所有“片段”“例”“主干”里的英文，必须是原句里**一字不差**的连续片段（大小写、标点、弯撇号 ’ 都要一致）。
- 句子必须是挑句表里的那几句，顺序一致。
- “成分”只能用：主句、主语、谓语、宾语、表语、宾语补足语、主语从句、宾语从句、表语从句、同位语从句、定语从句、非限制性定语从句、时间状语从句、原因状语从句、条件状语从句、让步状语从句、目的状语从句、结果状语从句、比较状语从句、方式状语从句、地点状语从句、现在分词短语、过去分词短语、不定式短语、动名词短语、介词短语、形容词短语、副词短语、同位语、插入语、并列结构、并列谓语、独立主格结构、比较结构、倒装结构、强调句、省略结构、there be 句型、形式主语、形式宾语、引语，写名称本身、不加括号；修饰谁、什么类型的补充都写进“作用”。
- “知识点·名称”只能用：主句、主语、谓语、宾语、表语、宾语补足语、主语从句、宾语从句、表语从句、同位语从句、定语从句、非限制性定语从句、时间状语从句、原因状语从句、条件状语从句、让步状语从句、目的状语从句、结果状语从句、比较状语从句、方式状语从句、地点状语从句、现在分词短语、过去分词短语、不定式短语、动名词短语、介词短语、形容词短语、副词短语、同位语、插入语、并列结构、并列谓语、独立主格结构、比较结构、倒装结构、强调句、省略结构、there be 句型、形式主语、形式宾语、引语、固定搭配、虚拟语气、被动语态、时态、情态动词、代词指代、平行结构、否定结构、双重否定、部分否定、比较级、最高级、名词化、介词 + which/whom、关系副词、what 从句、whether 从句、分隔结构、后置定语、多重定语、长主语。
- “翻译·方法”只能用：顺译、逆序译、拆分译、合并译、定语前置、定语后置拆译、词性转换、增译、省译、被动转主动、名词动词化、正反译、插入语处理。
- 祈使句没有主语：主干·主语写“（省略）”。
- 读懂步骤至少 2 步；拆解要覆盖句中所有从句、非谓语、插入语、并列等主要结构；知识点 2—5 个，挑本句最值得学的。
- 不要写参考译文（排版时直接用已定稿的译文）；“翻译·说明”要和参考译文的处理一致。
- 写完运行 `/opt/ttsenv/bin/python 六级/tools/长难句.py check <篇目>`，直到输出“全部通过”。
