## 判断标准（与四级、高考一致）

认真的英语老师或专业编辑会判错的就改，“试卷原文就是这样写的”不是保留错误的理由；英式/美式拼写、合法的新闻文体、引语中的口语、可加可不加的逗号都不改。事实错误要查证后才改（如 s33 祖尼人在新墨西哥州、Darwin 也用过 survival of the fittest）。
