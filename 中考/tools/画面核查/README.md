# 中考成品视频画面核查

**流程：先审截图，后生成视频（CLAUDE.md 踩坑 36）。**

专八大字版（2026-10-16 起）与中考共用 `layoutcheck.py`、`screens_fp.py`、`canary_layout.py`、`prep.py`，加 `--project 专八`（默认 中考，中考的用法和结果不变：40 篇 layoutcheck 改动前后输出完全相同）。

| 工具 | 查什么 | 花不花 token |
|---|---|---|
| `screens_fp.py shots/approve/check` | 画出全部屏的截图交给审阅员；审阅通过后登记程序指纹；`make_video.py` 生成前检查指纹，没登记就拒绝生成 | 不花 |
| `prep.py <截图目录> zNN… [--ref-only]` | 截出每屏（`extract.py`），写参考文件 `ref/zNN.txt`，核对屏数。每次都重写全部参考文件，要一次列出本批全部篇目 | 不花 |
| `pixelcheck.py <截图目录> zNN… [--as y3=z13]` | 画面文字与复核定稿一字不差：按定稿数据用同一程序重画每一屏，与视频截图逐块比像素。埋雷 `埋雷位置.json`（`canary.py`）15 处全部查出 | 不花 |
| `layoutcheck.py [zNN…]` | 排版毛病：行首缩进、标点挤压、孤字、释义断词、连字符断行、直引号、词汇栏留白、字号、标题。`make_video.py` 每屏自动调用。旧版程序上查出 328 处 | 不花 |
| `progdiff.py <旧版 make_video.py> [--css …] zNN…` | 新旧两版程序各渲染一遍直接比较，列出有实质变化的屏；`--css` 给旧版补上已知的无关整体变化（如 2 像素间距）。比 `changed.py` 准 | 不花 |
| `changed.py <旧截图目录> <新截图目录> zNN…` | 修改程序后重新生成：逐屏比出画面有变化的屏，交给审阅员的 `only` 参数（没变的屏已按最终状态复核过） | 不花 |
| `../workflows/zk-frame-qa.js`（`lenses: ["visual"]`） | 排版审阅员：每篇 1 人看最终版本的全部屏，找程序查不出的排版毛病。同时审阅排版埋雷副本（`canary_layout.py <截图目录> z01 y4`，5 屏故意做坏），必须全部查出 | 花 |
