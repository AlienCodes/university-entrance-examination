# 视频画面风格库（6 种，2026-10-13 为中考视频设计，以后任何视频都可以直接拿来用）

每种风格都是一份 CSS，**追加在生成程序的通用样式之后**覆盖颜色、字体、装饰和封面，不改版面尺寸。
样本图是用同一篇真实文章（2026 北京 阅读C）画出的效果，1920×1080（4K 视频的一半）。

## 怎么用到新项目

1. 把选中的 CSS 复制成新项目的 `tools/样式.css`（生成程序在通用样式之后追加它，见 `中考/tools/make_video.py` 的 `THEME`）。
2. 字体：这些风格用到的网页字体（Nunito、Fredoka、Baloo 2、站酷快乐体、霞鹜文楷、思源黑体等）都在 `中考/tools/fonts/`，连同 `fonts.css` 一起复制，`THEME_FONTS` 指向它。
3. 先出样片看效果：`/opt/ttsenv/bin/python 中考/tools/样式设计/render.py <风格.css> <输出目录>`，会画出封面、3 屏句子、1 屏超密的压力测试和手机尺寸缩略图，并检查对比度和“所有屏放得下、字号不比通用样式小”（`report.json`，FIT OK 才能用）。
4. 之后照常走 CLAUDE.md 的流程：先审截图（排版机械检查 + 带埋雷的审阅）再生成视频。
