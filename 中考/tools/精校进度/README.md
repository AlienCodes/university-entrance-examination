# 中考阅读精校记录

- `第一轮结果_*.json`：第一轮精校工作流（`../workflows/zk-proofread.js`）的完整输出。每组 4–6 篇，4 人分别从“与试卷原件一致、标点拼写、语法、逻辑”四个角度查错，每条发现再由 2 人独立核验（accept / amend / reject）。
  - `result.kept` 是两人都通过的，`result.dropped` 是至少一人否决的。被否决的也逐条人工过目，理由充分的照样采用（踩坑 #15）。
  - 第一轮的审阅文件是在补入 2025 北京 D 篇之前生成的，所以审阅编号 z35–z39 对应现在的 z36–z40（`第一轮结果_z30-z34_z36-z40.json` 里的 pid 是旧编号）。2025 北京 D 篇（现 z35）单独查一次，见 `第一轮结果_z35.json`。订正按篇名（“2026年 深圳 阅读B”）登记，与编号无关。
  - 每组都混入一篇埋雷副本（`埋雷位置.json`：z40 来自 z23、z41 来自 z31、z98 来自 z10），埋的错误必须全部查出。第一轮结果：z40 6/6（含段落合并）、z41 6/6、z98 4/4。
- `已决定不改.json`：人工判断后决定不改的条目和理由，写进下一轮的审阅文件，避免重复报。
- 采用的订正都写在 `../原文订正.json`（每条注明类型和理由，必须恰好匹配一处）。
- 第二轮终查（`../workflows/zk-final-check.js`）：已订正的文字再查一遍，每组 3–4 篇，2 人查错（标点语法 / 意思逻辑并检查已做的订正）、2 人核验（准确 / 严格编辑），只报确定的错误。两波各 3 组并行，每组混入一篇新的埋雷副本（`埋雷位置_第二轮.json`：z97、z98、z99；`埋雷位置_第二轮_第二波.json`：z94、z95、z96），每篇 4 处，**24/24 全部查出**。
  - 第一波（z01—z20）真实意见 8 条，采用 7 条（含一人否决、人工复核采用 1 条）；第二波（z21—z40）真实意见 4 条，采用 3 条，1 条双否决记入已决定不改。
  - 第二轮之后封版（`../../阅读/封版.json`，按篇登记）：z01—z20、z21—z40 全部封版，进入翻译标注。
