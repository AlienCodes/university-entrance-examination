# 中考翻译与生词标注复核记录

做法与专八、六级相同：每篇一位标注人写初稿（`../workflows/zk-annotate.js`，`check_ann.py` 自检通过），然后两轮复核（`../workflows/zk-zh-audit.js`）：每组 2–4 篇，4 人分别从翻译精准、中文地道、释义词性与漏标、全篇统一四个角度复核，每条意见再由 2 人独立核验。两人都同意的直接采用；有分歧的、被否决的、两人改法不同的逐条人工过目（踩坑 #15）。每组混入埋雷副本（在复核文件副本里故意改错，必须全部查出）。
