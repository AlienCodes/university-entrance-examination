# 清晰度：v3 样段 → v4 样段（老师模型，2026-11-04）

老师听 v3：“很多发音都没有发清楚……起码声音要清晰一点。”v3 的所有检查都过了，因为没有一项检查管清晰度。
下面的数字都由程序量出：`tools/tts/清晰度.py`（两个中文识别器 + 频谱），`高考续写/tools/声音对比.py`（全部检查、相似度、英文）。

## 结论

- **v4 成品**：`高考续写/预览/2026 新课标Ⅰ卷 读后续写 讲解 样段 v4（老师模型，清晰）.mp3`
  - 同样 14 段，125.8 秒；完整处理链；全部检查通过，有合格证（呼吸 0）。
  - 新加的清晰度关口也通过。
- **做法**：
  - 采样换成 VoiceTwin 的补救预设 lt6：温度 0.6、top_p 0.8，其余照旧。
  - 每个小段合成 6 次，选段时两个中文识别器一起打分。
  - 加音色还原：60—500 Hz 降 2.5 dB，5—9 kHz 升 2 dB。

| 量（中文小段 27 个，成品上量） | 老师真声 | v3 | **v4** |
|---|---|---|---|
| SenseVoice 字错误率 | 0.019 | 0.048 | **0.021** |

- 老师真声有两组：识别错误率用模型训练切片 30 条，在 Actions 上量，只出数字；频谱用 05.wav 讲课录音和训练切片。
- v3 识别差异里的 想好→三号、翻→分、几→鸡、法→发、半句→面就、以写→said，v4 都没有了。
- v4 剩下的中文差异：
  - 只有同音或近音：翻→饭、句→具、地→的；
  - 加上 她→他（识别器分不出）。

## 原因（量出来的）

1. **处理链不是主因。**
   - 把 v3 所选的原始小段逐步过处理链，识别错误率基本不变：原始 0.048 / 0.084，成品 0.048 / 0.082。
   - 只有擦音对元音降了约 1.3 dB（段内电平只往上补浊音）。
2. **合成采样。**
   - 运行 #19 一共 7 个候选，每个合成 3 次。下面是原始小段的两识别器字错误率：

   | 候选 | 改了什么 | 识别错误率 |
   |---|---|---|
   | g1 | 原样（即 v3 的设置） | 0.071 / 0.099 |
   | **lt6** | 温度 0.6、top_p 0.8 | **0.039 / 0.056** |
   | lt6ml | lt6 + 成句英文单独合成 | 0.041 / 0.062 |
   | lt6a0 | lt6 + 不用辅助参考 | 0.048 / 0.058 |
   | lt6r1 | lt6 + 换主参考 | 0.047 / 0.068 |
   | k5 | top_k 5 | 0.062 / 0.073 |
   | lt8 | 温度 0.8、top_k 10 | 0.071 / 0.095 |

   - 相似度全部在 0.92—0.93 之间，门槛是 0.88。
   - 语速：models.json 的 gptsovits.speed 和 identical.speed 都是 1.0，不是原因。
   - 版本：VoiceTwin 用 abe9843 + v2ProPlus，和我们的一致。
3. **音色发闷。** 所有候选的 4 kHz 以上能量都在 0.015—0.016，真声是 0.035—0.042，可见跟采样参数无关，问题出在 SoVITS 解码。和老师讲课录音比长时频谱（以 1 kHz 为基准）：
   - 125—500 Hz 合成多 2.0—3.1 dB；
   - 5—10 kHz 合成少 0.6—2.6 dB。

   按这个差做音色还原，在 lt6 上的结果：
   - 识别错误率不变（0.043 / 0.059 对 0.043 / 0.060）；
   - 4 kHz 以上能量 0.019 → 0.037；
   - 擦音对元音 −8.0 → −5.0 dB。

## 新关口（踩坑 115）

`tools/tts/清晰度.check`，每次 `讲解音频.render` 都跑。门槛以老师真声为基准，下面任何一项不达标就不出音频：

- 两个识别器的拼音错误率，各自 ≤ 0.045（真声 0.015 的 3 倍）；
- 4 kHz 以上能量占比 ≥ 0.025；
- 擦音对元音 ≥ −6.5 dB；
- 量不到擦音也报。

双向验证 `/opt/ttsenv/bin/python tools/防复发/验证/清晰度.py`：

- v3 报 3 项；
- v4 报 0 项；
- v4 低通到 3.5 kHz 后报 2 项。
