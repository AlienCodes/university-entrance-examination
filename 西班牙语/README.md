# 西班牙语阅读：逐句精读视频

用户 2026-10-09 发来一篇西班牙语短文（Word 文档）：《Mi pasión por los viajes 我对旅行的热爱》（每日一练 稳步提升），
要求：找最好的西班牙语配音，做成和四级一样的逐句精读视频（参考图就是四级视频的一帧）。

| 位置 | 内容 |
|---|---|
| `文章/es01.json` | 原文 9 句（2 段）、逐句中文翻译（文档原文，原样）、每句的生词栏（文档的 15 个重点词汇原样保留 + 21 个补充词条，经两位复核人核对） |
| `图片/es01_插图.jpg` | 文档里的插图（片头使用） |
| `tools/make_audio.py` | 朗读音频：默认音色 `qwen3_M1F5_25`（Qwen3-TTS 克隆，最像真人）；也可用 4 种 Supertonic 3 男声（`voices.json`） |
| `tools/make_video.py` | 生成视频（`--style C/1–6` 七种背景，预览见 `背景样式/`）：沿用四级设计方案 C 和四级 / 高考同一套成品核查 |
| `tools/batch.py` | 批量生成：开工前全部检查 → 音频 → 视频 → 核查，没通过自动重做，已是最新的跳过 |
| `tools/loudness.py`、`tools/buzz.py` | 响度一致、电磁音的测量（自测：`test_loudness.py`、`test_buzz.py`） |
| `tools/build_kit.py`、`kit/` | 给西班牙语老师的下载工具包（发布流程 `.github/workflows/release-es-kit.yml`，说明 `kit/使用说明.md`） |
| `配音选型/` | 西班牙语配音怎么选的：找了哪些模型、怎么测、结果、淘汰原因；5 份样音（已定：`qwen3_M1F5_25`） |
| `最终视频/` | 示例视频两版（默认背景 C、背景 5），旁边是 15+ 项核查记录 |

做法和标准沿用仓库根目录 `CLAUDE.md` 的铁律（响度、片头 1.5 秒、句间 0.8 秒、结尾 2 秒、标点停顿、无电磁音、4K、30 帧）。
西语和英语视频不同的地方（都写在程序开头的说明里）：3 秒短时响度波动只测朗读部分、不含片头片尾的规定静音（`loudness.py`）；
电磁音用梳状线自校准 + 全频段兜底，全频段超限时要前后两半都在才算（`buzz.py`）；逗号等处的 0.28 秒停顿在视频核查里逐处实测。
