# 西班牙语/ 文件夹里有什么

怎么安装、怎么生成视频、怎么加新文章，都在工具包最外层的 **`使用说明.md`**。这里只说明这个文件夹里每样东西是做什么的。

| 位置 | 内容 | 要不要动 |
|---|---|---|
| `文章/` | 每篇文章一个 JSON（西语原文、逐句中文翻译、每句生词）。`es01.json` 是示例，`模板.json` 是新文章模板 | 加新文章就在这里 |
| `图片/` | 片头插图 `篇目编号_插图.jpg`（可以没有） | 可以放插图 |
| `最终视频/` | 生成的 4K 视频和每个视频的 `…_核查.json`（每一项自动检查的结果）；自带示例 | 成品在这里 |
| `audio/` | 生成的朗读音频（MP3）和中西双语字幕（SRT），按音色分文件夹；`timings.json` 记每句的时间 | 不用动 |
| `截图/` | `--stills` 只出截图时放在这里 | 看完可以删 |
| `背景样式/` | 7 种背景的预览图（先看 `全部背景一览.jpg`）和说明 | 只看 |
| `配音选型/` | 5 种配音的试听样音（`样音_2026-10-15/`）、Qwen3 用的参考声音、选型过程和语音识别核对记录 | 只看；`参考音色/` 不要删（Qwen3 要用） |
| `models/` | 配音模型：`supertonic3/` 随包；`qwen3-base/` 另外下载解压（见 使用说明 第三节） | 不用动 |
| `tools/` | 全部程序（见下表）、音色设置 `voices.json`、列举逗号登记 `逗号停顿.json`、背景样式和字体 | 只改 `逗号停顿.json` |
| `kit/` | 安装用的依赖清单 | 不用动 |

`tools/` 里的程序（一般只用工具包最外层的 `生成视频.sh` / `生成视频.bat`，它调用 `batch.py`）：

| 程序 | 作用 |
|---|---|
| `batch.py` | 批量生成：开工前检查 → 朗读音频 → 4K 视频 → 核查，没通过自动重做，已是最新的跳过 |
| `make_audio.py` | 生成一篇的朗读音频（也能只做几句试听：`--sample`） |
| `make_video.py` | 用已有音频生成视频（或只截图：`--stills`），生成后自动核查 |
| `loudness.py`、`buzz.py` | 响度一致、电磁音的测量和标准（音频、视频都用它们检查） |
| `test_loudness.py` | 响度检查的自测：理想朗读必须通过、故意做坏的必须查出来 |
| `join_parts.py` | 把 Qwen3 模型的分卷校验、解压到 `models/qwen3-base/` |
| `qa_asr.py` | （可选）语音识别回转比对：找漏读、多读、读错 |
| `engines/` | 各配音模型的合成程序 |

工具包外层的 `四级/`、`tools/` 文件夹是西语程序共用的处理链、画面和核查程序，不用动。
