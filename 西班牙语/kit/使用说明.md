# 西班牙语逐句精读视频工具包 · 使用说明

把一篇西班牙语短文（原文 + 逐句中文翻译 + 每句生词）做成 **4K 逐句精读视频**：片头显示标题和插图，之后每句一屏——
上面是西语原文（生词带编号高亮），下面是中文翻译，右边是生词栏；配音逐句朗读，句与句之间固定停顿。
生成后程序自动核查（响度、电磁音、停顿、画面与朗读逐句一致……），**任何一项不合格就不出成品**。

工具包里自带一篇示例（`es01` 《Mi pasión por los viajes 我对旅行的热爱》）：示例视频在 `西班牙语/最终视频/`，可以先看效果。

---

## 二、电脑要求

- Windows 10/11、macOS 或 Linux；Python **3.10–3.13**（推荐 3.12）；**ffmpeg**（安装方法见下面）。
- 硬盘：基本安装约 1 GB；加 Qwen3 约再 2 GB（程序）+ 4.3 GB（模型），下载分卷时临时再要 4.3 GB。生成视频时至少留 3 GB。
- **Supertonic 音色**：轻、快，普通电脑就行。实测 4 核 CPU：合成加处理**每次**约 0.5 分钟（2 句短文）到 2 分钟（示例 es01，9 句、约 50 秒）。
  但每次合成都略有不同，**常常要做好几次才过检查**（主要卡在电磁音的梳状线残留，短文还有短时响度波动），程序会自动重做：
  2026-10-15 实测每次通过的机会：示例 es01 约一半；新写的短文约 1/4 到 2/3（句子很短、句中又有逗号停顿的，短时响度波动容易超；
  有的文章梳状线残留容易超）。默认最多试 15 次（见第四节 `--tries`），所以用 Supertonic 做一篇（音频 + 4K 视频）通常 5–20 分钟，
  运气不好时 30 分钟。
- **Qwen3 音色**（推荐，最像真人）：慢、吃内存。4 核 CPU 上约为实时的 10–20 倍（1 分钟的文章约 10–20 分钟），
  另加载模型 1–10 分钟；内存至少 16 GB（模型加载后约占 8–9 GB）。Intel 芯片的 Mac 装不了（没有新版 PyTorch）。
  检查一般一次就过（2026-10-15 实测：es01 第一次就全部通过；新写的短文 es02、es03 各试两个种子，4 次全部通过）；没过就自动换种子重做，最多 3 次。
- 视频：4K 画面截图 + 编码 + 核查，实测 es01（9 句）：背景 C、5、6 约 2.5 分钟，背景 1 约 3.5 分钟，背景 3（教室黑板）约 5 分钟。

## 三、安装

### 1. 安装 Python 和 ffmpeg

- **Windows**：
  - Python：到 <https://www.python.org/downloads/windows/> 下载 Python 3.12，安装时**勾选 “Add python.exe to PATH”**。
  - ffmpeg：在 PowerShell 里运行 `winget install --id Gyan.FFmpeg -e`（装好后把窗口关掉重新打开）；
    或到 <https://www.gyan.dev/ffmpeg/builds/> 下载 `ffmpeg-release-essentials.zip`，解压后把里面的 `bin` 文件夹加到系统环境变量 PATH。
- **macOS**：先装 Homebrew（<https://brew.sh>），然后 `brew install python@3.12 ffmpeg`。
- **Ubuntu / Debian**：`sudo apt install python3 python3-venv ffmpeg`。

### 2. 运行安装脚本

解压工具包，在工具包文件夹里：

- **Windows**：双击 `install_windows.bat`。
- **macOS / Linux**：打开终端，`cd` 到工具包文件夹，运行 `bash install.sh`。

安装脚本会：建虚拟环境 `.venv`（所有东西都装在这里，不改系统；删掉 `.venv` 就是卸载）→ 安装 Python 包 → 下载截图用的浏览器 →
检查 ffmpeg → **自检**（逐项列出 ✅ / ❌，Qwen3 没装时会提示）。可以重复运行，已装好的会跳过。

选项（Windows 写成 `install_windows.bat -Qwen3 -Mirror`）：

| 选项 | 作用 |
|---|---|
| `--qwen3` / `-Qwen3` | 另装 Qwen3 配音要的 PyTorch 等（约 2 GB）。分卷模型已经放在工具包文件夹里时，顺便合并解压 |
| `--mirror` / `-Mirror` | 在国内用镜像下载（清华 PyPI、npmmirror），快很多；镜像失败就去掉它再试 |
| `--python 路径` / `-Python 路径` | 指定用哪个 Python |

自检如果提示浏览器打不开，照它给出的命令运行（一般是在工具包文件夹里 `.venv/bin/python -m playwright install chromium`，
Windows：`.venv\Scripts\python -m playwright install chromium`）；Linux 上装好后还打不开，再运行 `sudo .venv/bin/python -m playwright install-deps chromium` 补系统库。

### 3. （推荐）安装 Qwen3 模型

Qwen3 模型约 4.3 GB，在 Release 里分成几个文件：`qwen3-tts-1.7b-base.zip.001`、`.002`……

1. 把所有分卷和 `SHA256SUMS.txt` 下载到**工具包文件夹**里；
2. 运行安装脚本时加 `--qwen3`（Windows：`install_windows.bat -Qwen3`），会自动合并、校验、解压到 `西班牙语/models/qwen3-base/`；
   已经装过基本版的，再运行一次加上这个选项即可。
3. 也可以单独解压：`.venv/bin/python 西班牙语/tools/join_parts.py 分卷所在文件夹`
   （Windows：`.venv\Scripts\python 西班牙语\tools\join_parts.py 分卷所在文件夹`）。
   它直接把分卷串起来读，不需要先拼出 4 GB 的整包；有 `SHA256SUMS.txt` 就逐个核对校验值；解压后可以加 `--delete-parts` 删掉分卷。

没有 Qwen3 也完全可以用：所有命令加 `--voice supertonic3_M1F5_25` 即可。

## 四、生成视频

下面的命令都在**工具包文件夹**里运行。macOS / Linux 用 `./生成视频.sh`，Windows 用 `生成视频.bat`（在文件夹地址栏输入 `cmd` 回车打开命令提示符），参数完全一样。

```
./生成视频.sh es01                                   # 生成一篇（默认音色 qwen3_M1F5_25，默认背景 C）
./生成视频.sh es01 --voice supertonic3_M1F5_25       # 用快速的 Supertonic 音色
./生成视频.sh es01 es02 es05 --style 5               # 几篇一起，紫黄撞色背景
./生成视频.sh all                                    # 文章/ 里的全部篇目（模板.json 除外）
./生成视频.sh all --stills                           # 只出截图，先看画面（几十秒一篇，不需要配音），在 西班牙语/截图/<篇目>_<背景>/
./生成视频.sh --list                                 # 列出音色、背景、篇目和每篇的生成情况
./生成视频.sh --list --voice supertonic3_M1F5_25 --style 5   # 按这个音色、这个背景看每篇做到了哪一步
./生成视频.sh --check                                # 安装自检
```

全部选项：

| 选项 | 作用 |
|---|---|
| `篇目编号 …` 或 `all` | 要做的文章（`西班牙语/文章/` 里的文件名，不带 `.json`） |
| `--voice 音色名` | 配音（见第五节）；不写就用默认的 `qwen3_M1F5_25` |
| `--style C/1/2/3/4/5/6` | 背景（见第六节）；不写就是 C |
| `--scale 2` | 画面倍数：2 = 3840×2160（4K，默认）；成品至少 2。`--stills` 时默认 1（1920×1080） |
| `--stills` | 只截图到 `西班牙语/截图/<篇目>_<背景>/`，如 `es01_C/`（000 是片头，001 起是每一句） |
| `--force` | 已经是最新的也重新生成 |
| `--tries 次数` | 音频检查没通过时最多做几次（默认 Qwen3 3 次、Supertonic 15 次） |
| `--list` | 列出音色、背景、篇目和每篇的生成情况（音频、视频是不是已是最新）；可以加 `--voice`、`--style` 看别的音色、背景（不写就是默认音色、背景 C）。已有的、核查通过的视频会顺便登记到 `西班牙语/最终视频/批量生成记录.json`（判断“已是最新”用的记录，不用管它） |
| `--check` | 安装自检（Python 包、ffmpeg、磁盘空间、真的打开一次截图用的浏览器、每个音色的模型和包） |

程序怎么做（一次启动，自动做到底）：

1. **开工前**先把要做的每一篇都检查一遍：JSON 格式、每句都有生词、生词在句中恰好出现一次、原文里没有数字和特殊符号、
   `逗号停顿.json` 能匹配上，还有音色模型、ffmpeg、磁盘空间。有问题就在开工前把**所有篇目的所有问题一次列出来**（哪一篇、第几句），
   不会做到一半才发现，也不用改一处、运行一次。
2. 逐篇：**朗读音频 → 4K 视频 → 核查**。已经是最新的会跳过（文章、插图、音频、背景、尺寸都没变），所以中途停了可以直接重新运行同一条命令接着做。
3. 音频检查没通过时自动重做：Qwen3 整篇换下一个随机种子（1234 → 1235 → 1236），Supertonic 重新合成（每次合成都略有不同，
   做好几次才通过是正常的，见第二节），最多 `--tries` 次。屏幕上每次都会打印没通过的是哪一项、数值多少。
   视频生成后会对视频里的声音再测一遍响度和电磁音；音频刚好卡在边上时，视频重新编码后可能差一点没过——这时也当作音频没过，
   音频和视频一起重做（算在 `--tries` 次数里）。
4. 任何一步失败就停下，告诉你是哪一篇、哪一步；最后打印汇总表。

成品：`西班牙语/最终视频/西班牙语 每日一练 西语标题 中文标题.mp4`（背景 1–6 时文件名末尾加「（背景 N 名称）」），
旁边的 `…_核查.json` 是每一项核查的结果。朗读音频和中西双语字幕在 `西班牙语/audio/音色名/`。

> 注意：同一篇、同一个背景，换音色重新生成会覆盖原来的视频（文件名里没有音色名）。想保留两个版本，先把旧的改个名。

## 五、选配音（`--voice`）

先听样音：`西班牙语/配音选型/样音_2026-10-15/`（都是 es01 全文，都走完整处理链、全部检查通过）。

| 音色 | 样音 | 说明 |
|---|---|---|
| `qwen3_M1F5_25`（默认，**推荐**） | `4_Qwen3真人感_推荐.mp3` | Qwen3-TTS 1.7B 克隆一个“更细、稍高”的西语男声，**最像真人**（自然度机测 4.0–4.3，Supertonic 约 3.4–3.8）；需要第三步的 Qwen3 模型，**慢** |
| `supertonic3_M1F5_25` | `2_高一些.mp3` | Supertonic 3 男声混合一点女声风格（约 135 Hz）；**快、轻量** |
| `supertonic3_M1F3_25` | `1_稍高.mp3` | 稍高一点（约 129 Hz） |
| `supertonic3_M1F5_30` | `3_再高一些.mp3` | 再高一些（约 139 Hz） |
| `supertonic3_M1` | `0_原声M1.mp3` | Supertonic 3 原声男声（约 121 Hz） |

- Qwen3 每段合成前都把随机种子重设为同一个值，同样的文字每次结果一样；Supertonic 每次合成略有不同。
- Supertonic 偶尔会吞音（选型时 es01 第 7 句 viajar 的 j 被吞掉），Qwen3 选型时 0 处读错。重要的视频建议用 Qwen3，并且自己从头听一遍。
- 音色设置在 `西班牙语/tools/voices.json`（语速、停顿、响度等），一般不用改。

## 七、加新文章

1. 复制 `西班牙语/文章/模板.json`，改名为新编号，例如 `es02.json`（编号只用字母、数字，不要空格）。
2. 用文本编辑器（Windows 记事本、VS Code 等，保存为 UTF-8）打开，填写：

```json
{
 "id": "es02",                       ← 必须和文件名一样
 "title_es": "西语标题",
 "title_zh": "中文标题",
 "series": "每日一练",                ← 片头上的系列名，可以不写
 "paras": [                          ← 段落列表；每段是句子列表
  [
   {
    "es": "Me llamo Ana y vivo en Madrid.",
    "zh": "我叫安娜，住在马德里。",
    "w": [                           ← 这一句的生词栏，至少一个
     {"h": "llamarse", "pos": "prnl.", "zh": "名叫", "surface": "Me llamo"},
     {"h": "vivir", "pos": "intr.", "zh": "居住，生活", "surface": "vivo"}
    ]
   }
  ]
 ]
}
```

（上面 `←` 后面是说明，真正的文件里不能写。）词条的几个字段：

| 字段 | 含义 |
|---|---|
| `h` | 词头（原形，如动词不定式）。有空格就算**短语**（显示砖红色），否则算**单词** |
| `pos` | 词性：`m.` 阳性名词、`f.` 阴性名词、`adj.`、`adv.`、`tr.` 及物动词、`intr.`、`prnl.`、`loc.` 短语（短语不显示 loc.，名词短语可写阴阳性） |
| `zh` | 中文释义（释义里的逗号处可以换行，尽量短） |
| `surface` | 句子里要高亮的**原样文字**：必须在这一句里**恰好出现一次**，大小写、重音都要一模一样；同一句的词条不能互相重叠 |
| `source` | 来源备注，可不写 |

规则（程序会检查，不合格会在开工前告诉你哪一句）：

- **每一句至少标一个生词。**
- 原文里不要阿拉伯数字（写成西语单词，如 `veinte`）和特殊符号（引号、括号、% 等）；可以用 `¿ ¡ . , ; : ! ? —`。
- 编号按词条在句中出现的先后自动排，`w` 里的顺序随意。

3. **逗号停顿**：逗号、分号、冒号、破折号处默认停顿 0.28 秒。**列举**（`A, B y C`）、并列形容词的逗号不该停顿，
   要登记在 `西班牙语/tools/逗号停顿.json`，按篇目、按第几句（整篇从 1 连续数）写逗号前面的文字：

```json
 "es02": {
  "3": [{"after": "manzanas,", "why": "列举：manzanas, peras y uvas"}]
 }
```

   加在文件最外层的大括号里（和 `"es01": {…}` 并列，前一项后面要有逗号）。`after` 必须能在那一句里找到，找不到会报错。没有列举就不用写。
4. 插图（可选）：放到 `西班牙语/图片/es02_插图.jpg`，片头右边显示。
5. 先出截图检查画面：`./生成视频.sh es02 --stills`，看 `西班牙语/截图/es02_C/` 里每一屏（文字、生词、翻译有没有错）。
6. 没问题就生成：`./生成视频.sh es02`（默认 Qwen3 音色）。**没装 Qwen3 的，用** `./生成视频.sh es02 --voice supertonic3_M1F5_25`
   （Supertonic 常要自动重做几次才过检查，见第二节）。生成后**从头到尾听一遍**（程序查得出响度、停顿、杂音，查不出某个词读得不地道）。
   文章至少要有 4 秒以上的朗读（一般 2 句以上），太短了 3 秒短时响度没法测，程序会报错。

翻译和释义的准确性程序查不了，请自己（或请同事）把关。

## 八、自动检查（不合格就不出成品）

| 检查 | 标准 | 在哪一步 |
|---|---|---|
| 生词 | 每句至少一个生词；生词在句中恰好出现一次、互不重叠 | 开工前、生成视频时 |
| 响度一致 | 整体 −16±0.7 LUFS；每句和中位数相差 ≤ 2 LU；3 秒短时响度波动 ≤ 1 LU（只算朗读部分：第一句开始到最后一句结束，句间、逗号的停顿照算；片头片尾的规定静音另有两项检查）；峰值 ≤ −1 dBFS（ITU-R BS.1770 独立测量） | 音频成品、视频音轨各测一次 |
| 没有电磁音 | 声码器梳状细线高出对照 ≤ 1.0 dB；任何窄带峰高出周围 ≤ 7.5 dB（超过时再看：前后两半都高出 7.2 dB 以上才算电磁音——电磁音是一直都在的固定频率细音，某个音一下的哨音不算） | 音频成品、视频音轨各测一次 |
| 停顿 | 片头静音 1.5 秒；句与句之间固定 0.8 秒且无声（读完停 0.5 秒切下一屏，再过 0.3 秒开读）；结尾静音 ≥ 2 秒；逗号、分号、冒号、破折号处 0.28 秒且无声（逐处实测） | 视频核查 |
| 画面 | 4K 16:9、恒定 30 帧、画面与声音等长、每屏放得下（字不小于下限）、背景字体不缺字、不出界 | 截图时、视频核查 |
| 内容 | 朗读文本和画面西语原文逐句完全一致 | 视频核查 |

> 只在前一半或后一半出现的强哨音不算电磁音（电磁音是从头到尾一直都在的固定频率细音），检查不会因此不通过；视频听起来像有哨音的，自己听一遍，必要时重新生成（Supertonic：加 `--force` 再运行一次；Qwen3 同一个种子每次结果一样，先 `python 西班牙语/tools/make_audio.py 篇目 --seed 1240` 换个种子（`python` 的写法见第九节），再运行 `./生成视频.sh 篇目`）。

**检查没通过怎么办：**

- **开工前就报错**（JSON 格式、生词找不到、数字、逗号停顿匹配不到）：所有问题一次列出来，按提示把它们都改好（`文章/篇目.json` 或 `逗号停顿.json`），再运行同一条命令。
  “不是合法的 JSON”多半是少了逗号、多了最后一个逗号、用了中文引号。
- **音频检查没通过**（响度、电磁音）：程序已经自动换种子 / 重新合成了 `--tries` 次。可以加大次数再运行同一条命令（如 `--tries 20`），
  或换一个音色（Qwen3 检查一般一次就过，但慢）。不要为了通过去改检查标准。
  短时响度波动总是差一点（1.0x LU）的，多半是句子太短、停顿太密（例如只有 2 句、句中还有逗号）：把文章写长一点（4 句以上）通常就好了。
- **“朗读部分只有 N 秒，短时响度波动测不了”**：文章太短，加几句再做。
- **“一屏放不下”**：这一句太长或生词太多，删几个生词、缩短释义，或把这一句拆成两句。
- **“字落到了系统字体”**：这个背景的字体里没有某个字（多半是生僻汉字），换个说法，或换背景（C 最全）。
- **“找不到 ffmpeg”**：见第三节第 1 步。**磁盘空间不够**：清理后再运行。
- **Qwen3 “模型没装好 / 缺少 Python 包”**：见第三节第 3 步；或先用 `--voice supertonic3_M1F5_25`。
- 其他报错：把屏幕上最后几十行原样复制下来发给维护工具包的人。

## 九、单独运行各个程序（进阶）

`python` 指工具包里的 `.venv/bin/python`（Windows：`.venv\Scripts\python -X utf8`，`-X utf8` 让中文路径和文件内容在 Windows 上不出错；
`生成视频.bat` 已经自动加上）：

```
python 西班牙语/tools/make_audio.py es01 --voice supertonic3_M1F5_25 --sample 试听.mp3 --sents 1-3   # 只做几句试听（不写正式音频；检查没过不出文件）
python 西班牙语/tools/make_audio.py es01 --voice qwen3_M1F5_25                        # 只做朗读音频
python 西班牙语/tools/make_video.py es01 --voice qwen3_M1F5_25 --style 5              # 用已有音频生成视频
python 西班牙语/tools/make_video.py es01 --stills --style 3                           # 只截图（1920×1080），写到 西班牙语/截图/es01_3/
python 西班牙语/tools/qa_asr.py --model 识别模型文件夹 es01 成品.mp3 --out 结果.md     # 语音识别回转比对（可选，见下）
```

截图用的浏览器默认是安装脚本装的 Chromium。想用电脑上别的 Chromium / Chrome，可以把环境变量 `ES_CHROMIUM` 设成浏览器程序的完整路径（一般用不到）。

试听样片和正式音频走同一条处理链、同一套检查：**检查没通过就不写文件**（直接再运行一次即可，Supertonic 每次不同）；
加 `--draft` 才会写出，文件名带 `_未通过`，只能自己听，不能给别人用。`--sents` 至少选 4 秒以上的朗读（一般 2 句以上）。

语音识别回转比对（可选）：把成品逐句识别一遍、和原文逐词比较，找漏读、多读、读错。识别模型约 490 MB，从
<https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-nemo-parakeet-tdt-0.6b-v3-int8.tar.bz2>
下载解压，`--model` 指向解压出来的文件夹。每一处差异都要自己听，判断是识别器听错还是真的读错。
