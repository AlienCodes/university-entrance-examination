# 西班牙语视频的 7 种背景样式（任选一种）

同一个生成程序，加一个 `--style 编号` 就换背景。不加 `--style` 就是 **C 四级默认**（和以前生成的视频完全一样）。
所有样式的版面尺寸、朗读时间轴、停顿、响度、4K 画质和成品核查都相同，只换颜色、字体、装饰和片头。

## 1–6 号样式在西班牙语里做的调整

这 6 种背景原本是给中考英语视频设计的，用到西班牙语时做了这些改动（C 不受影响，一个像素都没变）：

- **封面**：中考版封面是一行中文标题；西语版改成「西语标题 + 中文标题 + 插图」：西语标题用该样式自己的西文字体（Nunito、Baloo 2 或 Fredoka）占整行，最多两行，标题太长会自动缩小字号；下面左边是中文标题和「单词 / 短语」图例，右边是文章插图（每种样式配了自己的相框：照片胶带、磁贴、贴纸描边等）。
- **页眉里的西语标题**改用该样式的西文字体（C 用的是 EB Garamond 斜体）。
- **词汇栏字号放大**：起始 40px（C 是 30px），和中考正式版一样，手机上也看得清；放不下时自动缩小。
- **中文不断在词中间**：释义只在逗号、顿号后面换行（不会出现「巨 / 大的」），最后两个字不拆开，不会有一行只剩一个字；释义折到第二行时和第一行对齐。
- **编号徽章不贴字**：按每个字母的实际字形量出右边距，徽章和前一个字母之间一定留出空隙。

## 程序自动检查（不合格就报错，不出视频）

每一屏截图前都会检查，任何一项不合格都直接报错：

- 句子屏一屏放得下，原文字号不小于 48px、词汇字号不小于 22px（所有样式都查）；
- 封面各块（标签、西语标题、中文标题、插图、页脚、图例）不出画面、互不重叠、插图已加载（所有样式都查）；
- 字形检查（1–6）：画面上每一个字都由样式指定的字体画出，西语的 á é í ó ú ü ñ Á É Í Ó Ú Ü Ñ ¿ ¡ « » 和中文都不会落到系统字体（已用含全部西语特殊字符的测试句验证 6 种样式都齐全）；
- 横向出界（1–6）：原文、译文、词条、释义的每一段都在所在栏以内；页眉标题不会和「SPANISH READING」挤在一起。

这些检查都做过「埋雷」验证：故意放进缺字、过长不断行、页眉过长、图例压在插图上，6 种样式全部报出来；正常页面全部 0 处。
