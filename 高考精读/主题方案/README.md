# 柔彩插画：左下角绿色树苗的替代装饰（2026-11-10）

老师定高考精读视频用「柔彩插画」主题（`tools/video/themes/css/6_柔彩插画.css`），但不喜欢内容屏左下角的绿色树苗。
下面 3 个方案都是独立的 CSS 覆盖（接在 6_柔彩插画.css 之后加载），只换树苗那一层，左下角的薄荷绿底色顺带换成暖桃色；共用样式文件没动。

| 方案 | 文件 | 一句话 |
|---|---|---|
| A 热气球 | `装饰_A_热气球.css` | 淡紫气球加桃色、黄色竖条纹，下面挂小篮子，底下一朵小云；轻巧向上，跟右上角的纸飞机呼应 |
| B 叠书与铅笔 | `装饰_B_叠书铅笔.css` | 紫、桃、黄三本书叠起来，斜插一支淡紫铅笔；最贴学习主题，重心最低、最稳 |
| C 彩虹与云朵 | `装饰_C_彩虹云朵.css` | 桃、黄、紫三道半圆彩虹，两头各一朵白云；最柔和、最矮，几乎不占视线 |

- 对比图：`对比_装饰方案.png`（原版 + A/B/C 同一屏，右边是左下角原尺寸放大）；`缩略_320宽.png`（320 宽看整体）
- 重新生成：`python3 生成方案.py`（写出 3 个 CSS）→ 用 `中考/tools/样式设计/render.py <主题+覆盖.css> <输出目录> --quick` 渲染 → `python 拼图.py <输出目录的上一级>`
- 注意：小绿星点缀（左上角等）和中文左侧的绿紫色竖条没有改；封面插画里也有绿叶，需要的话再另做。
- render.py 现在的引擎里 `vs=30;` 已不存在，第 40 行断言会失败；本次在草稿区复制一份去掉断言再跑，仓库里的脚本没改。
