## 建议做法（按铁律 14、15：先样片、及时查）
1. 转录原文（扫描件）→ 程序与 识别.json 逐词比对，差异列表人工核（识别错 vs 转录错）。
2. 切句 → 标注生词 / 短语 → 翻译 + 释义（**顺序：标注 → 翻译与释义独立复核 → 修正 → 音轨 → 视频**，踩坑 14）。
3. 句子时间：识别对齐求每句起止；句间原有停顿保留，> 2 秒的等待压到 2 秒（说明、念题之间的长静音都算）。
4. 先挑最难的一段（采访 Part Two，对话、人名 Jeremy Bentham / Clifford Geertz）做样片：音轨 → 分屏 → 截图预检 → 截图 → 视频，全部检查 0 处，发样片给用户看，再做全片。
5. 是否包括考试说明、念题部分：建议整段录音按顺序都做（说明、讲座、采访、念题），用户说的是“这篇听力的原文”；10 道题若出现多题同屏，按**铁律 19**（题间空隙 + 浅灰细线，`tools/题目间隔.py`）。

7. 成品：`专八/听力/最终视频_原文/2025年 专八听力 原文精读.mp4`（文件名可再定），发布新 Release（Python zipfile，目标用分支名，下载核对）。
