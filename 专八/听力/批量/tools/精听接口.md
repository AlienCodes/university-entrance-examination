# 2009—2024专八原声精听：独立适配接口

本适配只新增 `精听.py`、`精听数据.py`、`精听自检.py`，不修改2025资料、旧视频、共享字体或共享项目注册表。

## 实际复用

`精听.engine()` 在当前Python进程注册“专八批量精听”，复制已有“专八听力”的水墨变体：

- 入口引擎：`专八/tools/make_video.py` 的 `layout`、`screen_checks`、`split_parts`、`frame_check`。
- 基础样式：`专八/tools/样式.css`；覆盖样式：`专八/tools/样式/C_水墨大字.css`。
- 字体：EB Garamond 700/800、霞鹜文楷700、思源宋体700、Inter700/800；`fonts/eb-garamond-bold.css` 与 `fonts/fonts.css` 及其二进制文件。
- 字号：`专八/tools/字号.json` 的 `C@水墨`，1080p基准英文73px、词汇40px，下限73/34，译文倍率0.752。实际截图3840×2160。
- 单词晴空蓝 `#1f6fd6`、短语翠绿 `#2a9142`；英文/译文在左、词汇栏在右；全部真粗体。
- 自动分屏仍调用 `专八/tools/分屏建议.py` 和 `分屏定稿.py`，保留其音频停顿与语义锚点规则。无法可靠切开的句子会停止，不能缩小字号硬挤。
- 原声检查复用 `专八/听力/原文/tools/原音音轨.py:seg_match`，没有调用2025固定WIN或旧增益/限幅入口。

## 每个精听单元一份JSON

单元可为一整年，也可按考试Section拆分；`id` 唯一。所有时间均为**原始录音绝对秒数**，不先自行扣片头音乐。英文字符偏移按Python字符串下标。

```json
{
  "id": "2009-A",
  "year": 2009,
  "section": "Section A",
  "title": "讲座标题",
  "genre": "讲座",
  "summary": "原文内容概括",
  "audio": {
    "sha256": "原始音频完整64位SHA256",
    "window": [12.0, 680.0]
  },
  "names": [],
  "待核": [],
  "sentences": [
    {
      "en": "Good morning, everyone.",
      "zh": "大家早上好。",
      "start": 12.1,
      "end": 13.8,
      "w": [
        {"t": "core", "h": "morning", "m": "n. 早晨", "sp": [[5, 12]]}
      ],
      "words": [["Good", 12.1, 12.4], ["morning", 12.4, 13.1], ["everyone", 13.2, 13.8]]
    }
  ],
  "splits": {},
  "review": {
    "status": "approved",
    "content_sha256": "由精听数据.content_sha(d)生成",
    "source": "实际审校记录的路径或说明"
  }
}
```

- `window` 是人工/程序根据正式开口和正文终点核定的窗口；它必须包含全部本单元句子。前导音乐在窗口外。本程序不凭响度猜哪一段是音乐。
- `w` 与现有 `data/vocab.json` 相同：`t=core/word/phr`、词条、释义、真实字符范围；每句至少一条，范围不能重叠或越界。
- `words` 可替换为 `word_alignment:[{"char":0,"char_end":4,"start":12.1,"end":12.4},…]`，后者直接绑定校定英文。没有这两者时短句仍可一屏展示；需要句内分屏时回到原引擎实际ASR定位，不按字符长度分配音频时间。
- fallback逐词必须真实相同（仅大小写和弯/直撇号规范化）；同词数的实词或否定变化也拒绝，不能按下标补造。已核OCR/缩写变体须用显式真实word_alignment，不自动比例估时。
- `splits` 沿用旧引擎按句号的结构，例如 `{"5":{"at":"However,","zh":["第一段译文，","第二段译文。"]}}`。中文必须原样拼回整句；`zh:"整句"` 表示各屏保留整句译文。
- 审校登记的内容摘要是去掉 `review` 对象后，对JSON按键排序并规范序列化所得SHA256；不能在翻译/词汇/时间更改后沿用旧摘要。`--draft` 只允许预览，正式视频会再次拒绝待核或过期登记。

## CLI

```bash
python 专八/听力/批量/tools/精听自检.py
python 专八/听力/批量/tools/精听.py unit.json prepare --original raw.mp3 --out 工作目录
python 专八/听力/批量/tools/精听.py unit.json precheck --autosplit --original raw.mp3 --out 工作目录
python 专八/听力/批量/tools/精听.py unit.json approve --review-note '实际样片与例外复核记录的路径或依据' --out 工作目录
python 专八/听力/批量/tools/精听.py unit.json video --out 工作目录
```

`all --review-note ...` 依次完成原声、AAC预演、分屏（加 `--autosplit` 时）、逐屏排版、核对登记、编码和成品独立核查。`audio` 只编译与AAC核验；`stills` 重查已编译输入再截图；`approve` 在核对当前截图后登记，生产编码缺该记录即拒绝；`verify` 只查现有成品。正式数据未定稿时，可用 `precheck --draft` 加 `preview --draft` 做技术预览；预览文件名明确“技术预览_译注未定稿”，只写 `preview-verification.json`，从不写发布 `meta.json`。

本机浏览器用 `--browser /usr/bin/chromium` 或 `TEM8_BROWSER`；HTTP预览借用已有 `高考听力/精读/tools/本机预览.py`，不放开file访问权限。自动分屏有无停顿退让候选时还需要既有spaCy模型；若给定的 `splits` 全部可行，则不需要重新推导分屏。

## 原音处理和关卡

新原声按铁律25：不增益、不限幅、不压缩、不重采样、不改声道。源文件先核SHA。仅保留窗口；句内停顿全部保留；句间超过2秒时，只删除中段经10ms RMS和峰值共同确认为纯静音的部分，两侧各留1秒；含呼吸或其他声音则整段保留并登记。

FLOAT WAV逐点比原声样本，追加1.5秒片头静音和至少2.2秒片尾静音。AAC192k预演先核原采样率、声道和语音样本；视频后再次独立核对（增益差≤0.05dB、SNR≥30dB、逐秒差≤1dB），不强制原音达到TTS的−16LUFS。

逐屏检查复用原有字号、字形/字体回退、横向出界、文字重叠、中文姓名不断行、词条/译文断行、分屏字号一致与封面核查。截图记录输入指纹和每张PNG的SHA。编码前重核，成品每屏取帧与源截图比，核4K/30fps、帧数、声画等长、原声、首尾静音及附件上限。

输出 `prepared.json`、`audio-precheck.json`、`screens.json`、`states.json`、`approved-screens.json`、`verification.json`、`meta.json`。只有 `verification.ok=true` 且非draft才写供发布使用的 `meta.json`，其中 `kind=text`、`mp4`、`mp4_bytes`、`mp4_sha256`、`原音_sha256`、`input_sha256` 和当前指纹可供批量工作流校验。工作目录可重建；重要输入、脚本与核验记录入Git，成品入Release。

## 已跑的最小音频测试

`精听自检.py` 包含9个实测/失败注入：2声道语音样本逐点不变、纯静音从5秒缩到2秒；间隙含声音时不删；正式窗口显式去前导；输入SHA/待核/译注摘要错误被拒；无法核定的词时刻不许按比例补造。字体二进制、浏览器与实际音频准备好后，仍须先跑真实短样和最难长句，不能仅凭这些结构测试放开批量。


## 2022完整源的已核低电平信号

`核验/2022-停顿边界复核.json`与源SHA绑定：仅2022 canonical `cc2bcead3fcfaf404840caa83e7a98efb7de446415388bd0fcc4803071e827a9`（或登记的编码源SHA）采用三段保护区间 `[54.68,84.85]`、`[586.87,767.60]`、`[804.25,834.32]`。这些区间含低电平非语音周期性信号，完整保留，不通过响度阈值将其当纯静音删掉；其他14年不套用。

编译自动读取该固定登记。输入可显式带 `audio.protected_source_intervals`，但必须与登记完全一致；错源SHA、错区间、缺登记均停止。`prepared.json`和timings保存登记SHA/实际保护区间，截图/发布指纹包含登记本身。登记变动后必须重新prepare、重审PNG。新增负例确认低电平信号可低于旧静音门槛但仍逐样本保留、错SHA/错段被拒、其他年份不会套用。

`精听版式预检.py`对草稿提供没有伪造时间的4K几何候选，`精听版式汇总.py`汇集为英文整句锚表。它们不是音频换屏审核，不能据此批准发布。`ordinal_hint`只供定位，正式说明插入后必须按英文整句一致合并，并重跑原音/字体/分屏/中文逐字核查。换屏首词缺真实ASR对齐会停止，不能跳过首词切到下一词。
