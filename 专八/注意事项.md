# 专八：全部注意事项（用户 2026-10-10：之前所有注意事项，新做的时候全部都要注意）

专八的工具全部由六级最终版复制（`专八/tools/`），下面每一条都有对应的程序检查或固定流程，不符合就报错、不输出成品。
铁律与踩坑的原文见仓库根目录 `CLAUDE.md`，具体做法见 `交接文档.md`。

## 文字（原文）

| 注意事项 | 怎么保证 |
|---|---|
| 原文必须与试卷一致，试卷本身的错误也要改（“原文如此”不是保留错误的理由，踩坑 16） | 四人对照试卷页面查错 + 两人核验（`workflows/tem8-proofread.js`），第二轮终查（`tem8-final-check.js`） |
| 文学选段以作者原著为准，不按考试规范改作者的写法 | 查错指令里写明，存疑时查原著 |
| 埋雷测试必须全部查出（踩坑 21） | `精校进度/埋雷位置.json`，每轮都埋 |
| 被否决的意见也要逐条人工过目（踩坑 15） | 每轮结果人工过目，记录在 `精校进度/` |
| 每条订正恰好匹配一次，写明理由（踩坑 17） | `extract_reading.py`：匹配不到或不唯一就报错 |
| 排版：直引号、空格、连字符、破折号、括号、全角标点（踩坑 7、18） | 与四六级共用的 `四级/tools/check_text.py` |
| 定稿后文字一改就必须重新精校（封版） | `阅读/封版.json` 指纹 |

## 翻译与生词

| 注意事项 | 怎么保证 |
|---|---|
| 每句至少标一个生词（铁律 1） | `check_ann.py`、`build_vocab.py`、`make_video.py` |
| 基础词以外的词一个都不能漏标；不区分大纲词和超纲词 | `check_ann.py` 覆盖检查（基础词表与四六级共用） |
| 复核顺序：标注 → 翻译与释义复核（两轮，埋雷）→ 修正 → 音频 → 视频；复核通过前不做视频（踩坑 14） | 固定流程；`build_vocab.py` 登记复核定稿指纹 |
| 高亮词与释义词性一致（踩坑 24）；同一句同词多处时用 `[ ]` 指定 | `ann_lib.find` |

## 音频

| 注意事项 | 怎么保证 |
|---|---|
| 男声 cet4_male（与四六级相同） | `make_audio.py` |
| 去除电磁音，任何频点高出周围 ≤ +3 dB（铁律 10） | `make_audio.py` 成品独立测量 |
| 响度 −16±0.7 LUFS、句间偏差 ≤ 2 LU、短时波动 ≤ 1 LU、峰值 ≤ −1 dBFS（铁律 2） | `verify_loudness` |
| 句间停顿 0.8 秒；逗号、冒号、分号、破折号停顿 0.28 秒；列举等不停顿的逗号不停顿（铁律 4、11） | `make_audio.py`，`make_video.py` 逐句核对 |
| 引号不停顿：合成时去掉引号（踩坑 28） | 送进模型的文字残留引号就报错 |
| 括号内容照读（踩坑 5）；数字、符号、斜杠不许残留（踩坑 19） | `read_text` 报错 |
| 数值范围读 to；金额缩写 $750m / £12bn；句末金额的句号；and/or（六级新增） | `make_audio.py` 朗读规则 |
| 合成前把朗读文本逐句预检一遍（六级新增） | 合成前人工过目数字、符号、外语词、人名 |
| 语音识别逐条核对：否定词、词尾 -ed/-s、漏读、多读、人名外语词（踩坑 23、27） | `qa_audio.py` + `audio/识别差异已核.md`，存疑的前后多留 0.5 秒重新识别、单句重合成 |

## 视频

| 注意事项 | 怎么保证 |
|---|---|
| 4K 16:9、30 帧恒定、声画等长（铁律 5，踩坑 8、22） | `make_video.py` 生成后自动核查 |
| 片头静音 1.5 秒，结尾静音 2 秒（铁律 3，踩坑 10） | 同上 |
| 字号下限：一屏放不下就拆屏，不硬挤；专八长句可拆多屏 | `fitcheck.py` 预检 + `分屏.json` |
| 朗读与画面英文逐句一致（踩坑 20） | `verify_videos` |
| 临时目录退出即删；磁盘剩余 < 3 GB 报错（踩坑 29） | `make_video.py` |
| 只按 PID 结束进程，不用会匹配到自己的 pkill/pgrep 模式（踩坑 12） | 操作规范 |
| 释义以“……”开头时居中显示（六级新增） | `make_video.py` 释义标 lang=zh-CN |
| 逐屏截图检查（六级新增，三人逐屏 + 核验，埋雷 18 处全部查出） | `workflows/cet6-frame-qa.js` 同法 |
| 交付前对全部成品统一核查，生成核查报告 | `verify_all.py` |
| 每完成一步都提交推送（铁律 9） | `batch_audio.sh`、`batch_video.sh` 每篇提交 |
