# 专八视频样式「书卷水墨」（2026-10-10）

**起因**：用户觉得四六级视频一直用同一种样子（绿色 + 米色），会审美疲劳，要求专八先暂停生成、换一个样子。

**过程**：
1. 先做了三种换色样片（深海蓝、夜间深色、酒红典雅），用户问“还有没有更好的”。
2. 六位设计者各按一个方向独立设计（杂志编辑、书卷水墨、现代极简应用、高级深色、学术出版、清新明亮），统一用 `render.py` 出图检查。
3. 用户看了初稿，**选定“书卷水墨”**：靛蓝书衣、宣纸题签、双线框、朱砂“专八精读”印章；句子页宣纸底色，靛青 = 单词（圆形编号），朱砂 = 短语（方角编号），中文译文用霞鹜文楷。

**定稿检查**（`render.py` 与 `covers.py`，设计时的出图与检查工具；路径指向当时的临时目录，复用时改路径）：
- 字号：对 t01—t10 全部 481 屏按已定分屏重新自动适配，全部放得下，**没有任何一屏的英文或词汇字号比原样式小**（英文平均 63.4px，原 63.3px；下限 48px / 22px）。
- 对比度（WCAG）：英文 14.8、中文 11.3、词条 13.6、释义 10.4、单词高亮 8.3、短语高亮 5.2，页眉页脚 ≥ 4.7。
- 封面：标题按字数排成一行（`title_slide` 给出字数 `--n`，字号 64—100px），不在词中间断行（初稿出现过“使用语|言”“调查|者”号）；中文译文末行不只剩一个字（`text-wrap: pretty`）。
- 生产渲染（`make_video.py` + `样式.css` + `fonts/`）与定稿出图逐像素一致。

**文件**：样式 `../样式.css`（追加在 `make_video.py` 通用样式之后，只改颜色、字体、装饰与封面，不改版面尺寸）；字体 `../fonts/`（霞鹜文楷 1.7.0，SIL OFL）；预览 `定稿_句子屏与封面.jpg`、`定稿_t01-t10封面.jpg`。

**中文放大（用户 2026-10-10 看了 t02 成品后：“中文字体可以稍微大点”）**：中文翻译 .68 → .78 倍英文字号（典型屏约 43px → 50px，按 1920 宽计），中文行距 1.65 → 1.55、英中间距 .5 → .4、英文行距 1.5 → 1.45（检查无重叠）。试了 .74/.78/.82 与不同行距共 8 种，选这一种：481 屏中 450 屏英文字号不变，31 屏长句英文小 2—4px，t09 第 18 句低于 48px 下限 → 在 “and I became conscious” 处加分屏。用户看了前后对比图后确认。词汇栏的中文释义未改。
