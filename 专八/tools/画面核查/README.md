做法与六级相同（`../../../六级/tools/画面核查/README.md`）：成品视频每屏截一张图（`extract.py`；`prep.py` 核对屏数 = 1 + 句数 + 分屏多出的屏数，专八一句可分三屏），三人逐屏查看（版面与编号、英文与结构、中文逐字），每条意见再由一人打开截图核验（`../workflows/tem8-frame-qa.js`，画面说明已按「书卷水墨」样式更新）。

**埋雷**（检查指令由六级改为专八，按踩坑 21 重新埋雷；`埋雷位置.json`，`canary.py` 用与成品相同的渲染程序做出带缺陷的屏）：
- q9（取自 t05）6 处：片头篇目错、编号圆圈缺失、短语用了单词的颜色、分屏第二屏中文被截短、the → this、复数丢 s —— **6/6 查出并核验确认**；
- q8（取自 t09）7 处：三屏中间一屏漏词、页脚 PART 3/3 写成 2/3、分屏第二屏显示第一屏的中文、形近错字 佘光 与 婉惜、词汇编号对调、整屏缺失 —— **7/7 查出并核验确认**（佘光 只有中文逐字一人查出，三人分工仍有必要）。

**结果**：t01—t10 **没有任何影响内容的错误**（英文逐词、中文逐字、词条、高亮、编号、句序、分屏、片头全部与定稿一致）。只有排版细节（核验确认，均不影响内容，**按用户决定不重做视频**）：
- 词尾 f 的弯钩与编号相碰；所有格撇号落在编号之后（drivers⑫’）；破折号、续接号 … 换到行首；
- 词汇栏较满时上下边距很小；中文释义里的英文撇号、引号按全角显示（Majesty’ s）；
- 英文里的中文注释（杨树）、（防水布）在行内断开；中文人名 理查德·帕克 在 · 处断行；
- 相邻两个同色短语看起来连在一起（t06 had … at that time、borrowed … for the day，词汇栏编号正确）；分屏页脚较长时进度条起点右移。

原始结果：`核查结果_q9_t01-t05.json`、`核查结果_q8_t06-t09.json`、`核查结果_t10.json`（t06—t10 第一次运行时遇到用量上限中断，限额恢复后续跑，已完成的结果复用）。

**字号按“看上去的大小”与中考对齐**（`../字号标定.py` → `../字号.json`）：同样 64px，EB Garamond 的 x 高度只有字号的 0.405，中考的 Nunito 是 0.50，
所以不按字号、按实测的 x 高度（英文、词条）和中文字面（常用字 100 个的墨迹高宽平均）对齐中考典型的一屏（40 篇 817 屏实测中位数：英文 Nunito 64px、
译文思源黑体 43.5px、词汇栏 40px）；每类文字取“与中考看上去一样大”和“这种画面原来的设计大小”中较大的（只放大、不缩小）。
英文下限 = 起始字号（与中考一样每屏英文同样大，放不下就分屏），词汇栏下限 = 0.85 × 起始（中考 95% 的屏不小于中位数的 0.85）。
样片.py 每次截图前用 `字号标定.py --check` 核对 字号.json 与实测一致（字体或样式改了就报错）。

**程序检查**（`中考/tools/画面核查/layoutcheck.py`，专八多开几项；`make_video.screen_checks` 每屏都跑，截图和生成视频用同一套）：
- 字体回退：Chrome 开发者协议问每个元素实际用了哪些字体，不许有系统字体（t03 审阅：英文里的中文注释“(防水布)”等 4 句落到系统黑体；
  已给 C 的英文补思源宋体、给背景 4 补思源黑体）。旧程序 4 处，新程序 0 处。
- 人名断开：登记在 `../人名.json` 的整名（t01—t10 全部 23 个含间隔号的人名、刊名）不许拆到两行（t03 审阅：“理查 / 德·帕克”）；
  中文里每个间隔号都必须属于登记的整名（`make_video.check_names`），新篇目出现新人名先登记。旧程序 1 处，新程序 0 处。
- 分屏字号：一句分成几屏时各屏英文、词汇栏字号相同（取最小，`make_video.layout`；t03 审阅：第 20 句两屏词汇栏 40/35px）。旧程序 1 处，新程序 0 处。
- 词条间距（背景 2 的“backn.”）、大写 I 短横（圆体 Nunito 和 Baloo 2 的 I 与 l 分不清，背景 1–6 照中考加，Baloo 2 的短横位置另行实测）、
  词条省略号（显示成“…”；t03 的数据本来就是“…”，审阅员看到的三个点是 EB Garamond 的省略号字形本身较宽）、片头标题按文字本身量（背景 3 的粉笔下划线不算）。
  每项都在故意做坏的页面上查出、在正常页面上为 0。
- 共用样式库的字形（每个字都由样式字体画出）、横向出界、封面各块不出界不重叠；徽章贴字仍只由程序查（审阅员看不出同色徽章贴字 1 像素）。
