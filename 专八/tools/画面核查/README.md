- q9（取自 t05）6 处：片头篇目错、编号圆圈缺失、短语用了单词的颜色、分屏第二屏中文被截短、the → this、复数丢 s —— **6/6 查出并核验确认**；

- 词汇栏较满时上下边距很小；中文释义里的英文撇号、引号按全角显示（Majesty’ s）；
- 英文里的中文注释（杨树）、（防水布）在行内断开；中文人名 理查德·帕克 在 · 处断行；
- 相邻两个同色短语看起来连在一起（t06 had … at that time、borrowed … for the day，词汇栏编号正确）；分屏页脚较长时进度条起点右移。
