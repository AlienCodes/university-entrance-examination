# 全局规则（50 篇全部检查一遍并统一）
1. 宾语、宾语从句与它所属的动词同一层（主句的宾语从句 = 第 1 层；第 2 层从句里动词的宾语 = 第 2 层）。
2. 宾语补足语（to do / doing / done / as B 等，拆解里成分写“宾语补足语”的）单独切成一块时，比它的动词所在的块低一层；它自己的修饰语再往下一层；超过第 4 层时保持第 4 层。
3. 并列成分（并列宾语、并列谓语）与它们并列的那一项同层，不算修饰语。
