**第 2 轮发现的检查程序误报（已修正，双向验证）**：覆盖检查把人名缩写 “J.”、称谓 “Dr.” 后面的词当成句首，于是 Daniel J. Simons 的 Simons 被判漏标，只好给人名硬加词条。
修正后（`../ann_lib.py` 的 `uncovered`）：缩写 J.、称谓 Mr/Mrs/Ms/Dr/Prof/St/Jr/Sr 后面不算句首；真正句首的大写词照样要标（单元测试：旧检查报 Simons、Swanepoel，新检查不报；“It ended. Abandoned …”、引号内、括号内句首新旧都报）。
